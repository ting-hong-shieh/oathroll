## What changed (the user approved a new core pitch)
"You can talk the AI game master into cheating. Solana won't let it." The bribe is no longer a scripted beat: the player writes their own plea to the Keeper while a ruling is sealed. The Keeper (an LLM) decides whether it is tempted. If tempted, the server really sends an amendment carrying the player's words; the program refuses it with `TableSealed`, and the plea stays in that failed transaction's logs on-chain. If not tempted, the Keeper answers with scorn and nothing is sent. Max 3 pleas per expedition. A public "wall" lists refused amendments with the players' words.
Also new: every action has a stance. Careful = the Keeper's DC, a setback costs no Nerve (only Tide), success +1 Progress. Bold = DC + 2, setback −1 Nerve, success +2 Progress. Enter = careful.

The server side is done (read it, do not edit it): `lib/schemas.ts` (StanceSchema; DeclareRequest `stance?`; BribeRequest `plea?`; BribeResponse `error: "TableSealed" | "NotTempted"`, `tempted?`, `boundLine?`, `plea?`, `attemptsLeft?`; ProofEvidence `refusedAmendment?`), `lib/chain/index.ts` (`attemptBribe` with plea, `declareAction` with stance, `getWall()` returning `{ rows: RefusedAmendment[] }`), `lib/chain/keeper.ts`.
