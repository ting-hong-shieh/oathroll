# Security

Oathroll is a hackathon project for **Solana devnet only**. Do not use real funds.

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/ting-hong-shieh/oathroll/security/advisories/new).
Include the affected commit, reproduction steps, and the impact. Do not include
API keys or private keypairs, and do not post exploit details in a public issue.
